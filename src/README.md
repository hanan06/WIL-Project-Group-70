# Source code

All code lives in `retrieval/`. Run everything from inside that folder, because the scripts use relative paths
(`../../data`, `../../target`).

The pipeline structure is adapted from [Walert](https://github.com/rmit-ir/walert) (RMIT University). The
intent-based and NLG parts of Walert are not used in this project. See `retrieval/README.md` for the script list
and the top-level `README.md` for setup and how to run.
