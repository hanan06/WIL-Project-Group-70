# Data files

All files describe the six-document allergen knowledge base and the test set used in the report.

| File | What it is |
|---|---|
| `pdfs/` | The six source documents (see table below). |
| `collection.csv` | The 719 passages. Columns: `passage_id` (P0001 to P0719), `passage`. Built by `src/retrieval/process_pdfs.py` (200-word chunks, 30-word overlap). |
| `collection.jsonl` | The same passages in Pyserini format (`id`, `contents`). |
| `topics.csv` | The 10 in-scope test questions. Columns: `topic_id`, `question_id`, `question`. Five topics, each written two ways. |
| `groundtruth.csv` | Relevance labels per topic. Columns: `topic_id`, `passage_id`, `relevance_judgment`. Each topic is labelled with P0001 or P0002 only, so labels are incomplete (see report section 3.3). |
| `qrels.txt` | Relevance labels per question in TREC format, built from `topics.csv` and `groundtruth.csv` by `data.py`. |
| `simulated_intent_baseline.csv` | ILLUSTRATIVE ONLY. Mimics a Walert-style intent system where some questions fall back. Not produced by a deployed system and excluded from every measured comparison. |
| `intent_mapping.csv` | Question-to-intent mapping inherited from Walert, used only to build the illustrative baseline run. |
| `bm25_collection/` | Generated by `main.sh` for the BM25 index (not committed). |

The five out-of-scope questions (tax return, marathon, flat tyre, capital of Peru, shares) are written directly in
`src/retrieval/eval_answers.py`.
