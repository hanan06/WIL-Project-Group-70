# A Food Safety & Dietary Risk Assistant
 
We are building a Retrieval-Augmented Generation (RAG) chatbot that helps consumers make safer, more informed food choices by answering everyday questions about food safety, storage, and allergen risks. The project is inspired by and reproduces core components of [Walert](https://github.com/rmit-ir/walert), a conversational agent developed at RMIT University's School of Computing Technologies.
 
This project is developed as part of **COSC2669 - Case Studies in Data Science (WIL Project)** at RMIT University.
